# Kieselstein-Addons

Addons für Kieselstein ERP, gebaut mit dem [Basiskit](https://github.com/mifreudenthaler/kieselstein-addon-basiskit).

- Neues Addon: Kieselstein-Seitenleiste → **Neues Addon anlegen**
- Entwickeln: Datei des Addons öffnen → **Flamme** (Live-Modus)
- In den Test laden: **Wolke** im Editor; in die Produktion über **Ausrollen** in der Zentrale

`basis/` ist die Basisschicht des Basiskits (nicht ändern – kommt mit Updates der Erweiterung).
Hinweise für Agenten stehen in `AGENTS.md` jedes Addons.
